# 离线环境说明

发行目录已经包含运行所需的软件依赖：

- `runtime/cpu/env`：CPU 推理环境。
- `runtime/cuda/env`：NVIDIA CUDA 推理环境。
- `runtime/amd/env`：AMD ROCm/HIP 推理环境。
- `runtime/miniconda`：环境维护工具。
- `engine/CCCP-Engine`：仅用于加载与推理的 CCCP 运行时。
- `toolchain`：首次运行时离线编译加速算子所需的工具。

用户只需双击 `CCCP-Launcher.exe`，不需要安装 Python、Miniconda、PyTorch 或编译器，也不需要运行 pip/conda。不要单独复制 EXE，缺少上述目录时推理和自动编译会失败。

完整离线目录未压缩时体积较大，主要来自 AMD ROCm/HIP、NVIDIA CUDA 和三套独立 PyTorch 动态库；这不是模型权重。发行封装会删除 Miniconda 已下载包缓存，但保留环境管理器、三套可运行环境和首次编译工具链。用户只需把全部发行分卷解压一次，之后直接双击 EXE；程序不会在首次启动时再次解压、安装或下载依赖。

ModelScope 是默认模型下载源，HuggingFace 为备用源；下载模型本身需要网络。本地模型推理、已有配置加载和算子编译均可离线完成。

CPU 会自动启用 Q4 执行映像、融合算子和码本复用缓存。NVIDIA/AMD 环境只在检测到对应驱动与设备后开放；显卡驱动必须由操作系统安装，不能包含在便携应用中。

MoE 与 Dense VQ 共用这三套环境。模型类型和投影布局完全由模型目录内的 `cccp.json` 声明；发行包不需要为每个模型复制一套 Python 环境。Dense 模型不存在专家扫描或专家配置，仍会自动使用对应设备的融合投影、KV 缓存和生成接口。

CPU v192 原生算子已随包预编译；只有预编译文件失配时才会离线应急编译。NVIDIA/AMD 在首次适配新显卡架构时会离线编译一次并缓存；NVIDIA 支持 RTX 20 系 SM75、RTX 30 系 SM86、RTX 40 系 SM89、H20/H100 SM90 与 RTX 50 系 SM120，并自动选择当前设备目标，不会沿用另一台电脑的旧架构。缓存按后端、显卡架构、运行时版本和算子源码指纹隔离，并存放在稳定的本机应用数据目录；移动或升级启动器不会触发无意义的重复编译。终端会明确显示缓存命中或首次构建；真正编译时显示活动进度条、后端、已用时间、5 秒心跳和编译器输出，不会无提示假死。

模型、数据集和第三方组件分别适用其各自许可证。发行包不包含模型权重，也不包含 CCCP 量化/训练框架及其开发工具。
